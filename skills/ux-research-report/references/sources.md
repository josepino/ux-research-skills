Per-topic notes: the audience matrix, shareout formats and the insight-to-spec bridge are heuristics of ours built from the sources above; the durations in `shareout-formats.md` are labeled heuristics, not measurements. The HTML renderer is original code with no external dependencies.

## Reviewed, little or no use for this skill
- https://maze.co/platform/ux-reporting/ : product page (automatic Maze reports); only confirms that tools generate editable reports.
- https://miro.com/templates/ux-research-repository/ : repository template; little value for the report.
- https://miro.com/templates/eisenhower-matrix/ : generic urgent/important matrix; mentioned only as a prioritization analogy.
- https://www.airtable.com/templates/design-and-ux : template catalog, nothing specific.
- https://media.nngroup.com/media/reports/free/How_to_Conduct_Eyetracking_Studies.pdf : eyetracking (2009), not applicable to reporting.
- https://assessment.uflib.ufl.edu/wordpress/files/2022/03/Usability-User-Experience-Report-Spring-2021_FINAL.pdf : real usability report example (15 users: 5 undergraduate, 5 graduate, 5 faculty); useful as a model, no figures reused.

## Discrepancies between sources
- Report order: conclusions first (Uxcel, Looppanel) vs. purpose/method first (classic order, UX Design Institute). Resolved in `pyramid-structure.md`: one-line purpose and answer on page one, classic order in the body.
- Researcher opinion: Ramotion says to exclude it from results; User Interviews allows offering it after the analysis. Resolved: separate evidence from judgment.
