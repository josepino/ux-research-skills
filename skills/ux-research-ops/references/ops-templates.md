# Operations templates

Translate headings and labels to the user's language when producing these.

## Session notes
```markdown
# Session [participant ID] — [date] — [study]
Interviewer: … · Note-taker: … · Duration: … · Recording: yes/no (path)
Profile: …

## Observations (facts)
| Min | Observation | Verbatim quote | Emotion | Code/tag |
|---|---|---|---|---|

## Interpretations (kept apart from facts)
- …

## Surprises / contradictions
- …

## Open questions
- …
```

## 30-minute debrief (post-session or daily)
```markdown
Goal: identify the main problems and possible quick solutions.
Method: 3 min individual (sticky notes, one idea per note) → 7 min sharing → group → parking lot.
Board sections: Conclusions · Needs · Problems · Goals · Parking lot
Prompts: "What surprised us?", "What did they say or do that we did not expect?", "What confirms/contradicts our assumptions?"
Minutes: learnings · surprises · contradictions · open questions · next steps · owners
```

## Team note-taking guide
```markdown
1. One file per session using the template.
2. Facts and quotes in quotation marks; interpretations in a separate section.
3. Participant IDs (P01…), never real names in notes.
4. Tags from the shared list (see the codebook).
5. Upload notes the same day.
```

## Naming convention
`YYYY-MM-DD_study_type_id_vNN.ext` — lowercase, underscore between fields, hyphen within fields, no accents or spaces.

## Identity table (restricted)
Keep it outside the shared repository, with restricted access.
```
| Code | Role | Consent reference | Access |
|---|---|---|---|
| P01 | [role] | [consent file / date] | restricted |
```

## Interview snapshot (1-minute read; adapted from LogRocket)
```markdown
Participant: P07 (code; photo only with consent) · Date · Interviewer
Key facts: …
Insights (2-4): …
Opportunities / next steps: …
Memorable quote: "…"
Links: recording · notes · board
```

## Top findings board with tally (NN/g)
```markdown
| Finding (usability-oriented phrase) | P01 | P02 | P03 | P04 | Total |
|---|---|---|---|---|---|
```
One single list per study; the facilitator writes it; photograph or export it at the end of each day.

## Color legend (put it inside the file)
Green works · Red pain · Orange neutral/mixed · Blue repeated · Purple outlier · Yellow key quote · Brown follow-up (adapted from Lyssna). Use few colors and always the same legend.
